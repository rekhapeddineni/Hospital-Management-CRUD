
# Hospital Management System

## Aim
To develop a CRUD application using AI-generated code
and integrate version control using Git and GitHub.

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
- Git
- GitHub

## Features
- Add Patient
- View Patient Records
- Update Patient Details
- Delete Patient Records
- Search Patients

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Perform CRUD operations.

## Data Storage
Patient records are stored using browser LocalStorage.

## Conclusion
Successfully developed a Hospital Management System
CRUD application using HTML, CSS and JavaScript.
